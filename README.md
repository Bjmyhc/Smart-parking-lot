# 智能停车场项目 - 旧版（已废弃）

> 此 `main` 分支为早期 **WiFi + OneNET 直连** 方案，**已废弃，不再维护**。
> 请切换到当前开发分支 **`multi-node-arch`**。

## 为什么废弃

早期方案采用 ESP8266 直连 OneNET（OneNET 直连模式），存在以下问题：

- 每个车位节点需独立上网，多车位扩展成本高、部署困难
- WiFi 无线覆盖有限，不适合大面积停车场
- 通信链路为透传，无协议帧、无轮询调度，易碰撞丢数据
- 代码结构松散，留有大量临时修复脚本（fix*.ps1、temp_*.c）

## 新架构（multi-node-arch 分支）

- STM32 节点（超声波 + 地磁）通过 **LoRa 433MHz 定点传输** 上报 ESP8266 网关
- 网关通过 **MQTT 网关+子设备模式** 代子设备上报 OneNET 云平台
- Web 前端实时监控 + 远程控制（LED 开关）
- 多车位轮询防碰撞、离线自动恢复、AP+Web 配网
