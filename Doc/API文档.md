# OneNet 智能停车场设备 API 文档

## 设备信息

- **产品ID**: `53BV12EYcY`
- **设备名称**: `park1`

---

## 一、通信主题

| 功能             | 主题                                               | 权限 |
| ---------------- | -------------------------------------------------- | ---- |
| 设备属性上报     | `$sys/53BV12EYcY/park1/thing/property/post`      | 发布 |
| 设备属性设置     | `$sys/53BV12EYcY/park1/thing/property/set`       | 订阅 |
| 设备属性设置响应 | `$sys/53BV12EYcY/park1/thing/property/set_reply` | 发布 |

---

## 二、属性列表

| 属性标识          | 类型  | 读写 | 说明                                     |
| ----------------- | ----- | ---- | ---------------------------------------- |
| `ParkStatus`    | int32 | 只读 | 车位状态（0=空闲，1=有车，2=疑似僵尸车） |
| `GeoMagnetic`   | int32 | 只读 | 地磁传感器采样值                         |
| `Ultrasonic`    | int32 | 只读 | 超声波距离值（cm）                       |
|  `OccupiedTime` | int32 | 只读 | 连续占用时间（秒）                       |

---

## 三、API 接口

### 1. 属性设置请求（平台下发）

**主题**: `$sys/53BV12EYcY/park1/thing/property/set`

**请求格式**:

```json
{
    "id": "请求ID",
    "params": {
        "属性名": {"value": 属性值}
    }
}
```

**示例 - 设置设备参数**:

```json
{
    "id": "12345",
    "params": {
        "Param1": {"value": 100}
    }
}
```

---

### 2. 属性设置响应（设备回复）

**主题**: `$sys/53BV12EYcY/park1/thing/property/set_reply`

**响应格式**:

```json
{
    "id": "请求ID",
    "code": 响应码,
    "msg": "响应消息"
}
```

**响应码说明**:

| code | 说明         |
| ---- | ------------ |
| 200  | 成功         |
| 400  | 请求格式错误 |

**成功响应示例**:

```json
{
    "id": "12345",
    "code": 200,
    "msg": "success"
}
```

**失败响应示例**:

```json
{
    "id": "12346",
    "code": 400,
    "msg": "invalid json"
}
```

---

### 3. 属性上报（设备主动上报）

**主题**: `$sys/53BV12EYcY/park1/thing/property/post`

**上报格式**:

```json
{
    "id": "时间戳",
    "params": {
        "ParkStatus": {"value": 1},
        "GeoMagnetic": {"value": 450},
        "Ultrasonic": {"value": 25},
        "OccupiedTime": {"value": 3600}
    }
}
```

**属性值说明**:

| 属性             | 值范围 | 说明                        |
| ---------------- | ------ | --------------------------- |
| `ParkStatus`   | 0      | 空闲                        |
|                  | 1      | 有车                        |
|                  | 2      | 疑似僵尸车                  |
| `GeoMagnetic`  | 0-4095 | ADC采样值，阈值判定车位状态 |
| `Ultrasonic`   | 0-400  | 距离（cm），0表示无有效数据 |
| `OccupiedTime` | 0-     | 连续占用时间（秒）          |

**触发时机**:

- 定时上报（每5秒）
- 收到属性设置请求后立即上报

## 四、车位状态判定逻辑

### 1. 双传感器融合算法

```
条件1: 地磁值 > 阈值 → 可能有车
条件2: 超声波距离 < 阈值 → 确认有车

状态判定:
- 空闲: 条件1不满足 OR 条件2不满足
- 有车: 条件1满足 AND 条件2满足
- 僵尸车: 有车状态持续超过设定时间（如7天）
```

## 六、网站端实现建议

### 1. 获取车位状态
- 订阅 `$sys/53BV12EYcY/park1/thing/property/post` 主题
- 设备会每5秒上报一次车位状态

### 2. 设置属性
- 发布消息到 `$sys/53BV12EYcY/park1/thing/property/set`
- 订阅 `$sys/53BV12EYcY/park1/thing/property/set_reply` 获取响应

### 3. 僵尸车告警

- 监控 `ParkStatus` 属性，当值为2时触发告警
- 可结合 `OccupiedTime` 显示占用时长
