## 3. 归档命令（可复现，含核对）

```powershell
# 归档目录（仓库外）
$dst = 'G:\All_Project\AI_Project\_firmware_baseline\20261009'
New-Item -ItemType Directory -Force -Path $dst | Out-Null

$ws = 'G:\All_Project\AI_Project\Smart-Paring-Iot'
Copy-Item "$ws\Node\BootLoader\Output\boot.bin"                "$dst\boot.bin"
Copy-Item "$ws\Node\Firmware\Output\app.bin"                   "$dst\node_v2.610_app.bin"
Copy-Item "$ws\Node\Firmware\Output\node_v2.610.bin"           "$dst\node_v2.610_ota.bin"
Copy-Item "$ws\PlateRecognitionIDF\build\plate_recognition.bin" "$dst\plate_recognition_P5.80.bin"

# 指纹
Get-ChildItem $dst -File | Where-Object Name -ne 'SHA256SUMS.txt' |
  ForEach-Object { "$((Get-FileHash $_ -Algorithm SHA256).Hash)  $($_.Name)" } |
  Set-Content "$dst\SHA256SUMS.txt" -Encoding utf8
```

**核对**：烧录前/回退后，用 `Get-FileHash <文件> -Algorithm SHA256` 与上表比对，一致才说明"烧的是基线那一份"。

## 5. 回退方法（出问题时怎么用这份归档）

| 要回退什么 | 用哪个文件 | 怎么烧 |
| --- | --- | --- |
| 节点 App | `node_v2.610_app.bin` | 串口线烧（Keil/J-Flash/或 BootLoader 的串口升级）；**注意**：Boot 不动 |
| 节点 App（走 OTA） | `node_v2.610_ota.bin` | 由网关 OTA 下发（需先把网关升/退到兼容版本） |
| 节点 Boot | `boot.bin` | 串口烧（**Boot 没改过，一般不需要**） |
| 摄像头 | `plate_recognition_P5.80.bin` | 串口/合并镜像烧；烧完看开机横幅是不是 **P5.80** |
| 网关 | `gateway_source.txt` 记的 git 提交 | `git checkout <SHA>` 后重编（或归档时补存的网关 bin 直接烧） |

> ⚠ **回退配对提醒**（本次改造引入）：数据帧 v4 是**结构性变更** → 节点与网关必须**成对升级、成对回退**。
> 单独退一侧 = 数据帧长度不符 = **车位数据全丢**（症状会被"未同步"诊断日志指出）。详见方案 §11。
