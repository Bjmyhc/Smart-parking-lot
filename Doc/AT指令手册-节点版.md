# 车牌识别摄像头 · 节点侧对接口（精简版）

> 给**节点单片机**的开发者。全量手册见 `AT指令手册.md`，这里只留对接必需的东西。
> 对应固件：`PlateRecognitionIDF` **P5.79**。

---

## 1. 接线与串口

| 项 | 值 |
| --- | --- |
| 摄像头侧 | UART1，**TX = GPIO1**，**RX = GPIO2** |
| 节点侧 | USART3：摄像头 TX → 节点 RX(PB11)，摄像头 RX → 节点 TX(PB10) |
| 参数 | **115200，8N1，无流控**，3.3V TTL，**必须共地** |
| 方向 | 摄像头 = **从机**：平时一个字都不发，也不做心跳；只有被 `AT+RUN` 触发才回一行 |

> ⚠️ 别接错口：摄像头还有一条 **921600** 的控制台口（USB/CH340）是给人调试用的，接了也不认节点协议。

---

## 2. 节点只需要做三件事

### 2.1 上电自检（可选，但建议）

```
发: AT+CTRL=NODE      →  OK          (确保控制权在节点手里，上电默认就是)
发: AT                →  OK          (探活；1 秒内没回说明线/波特率有问题)
```

### 2.2 检测到车 → 触发一帧

```
发: AT+RUN
（受理时摄像头什么都不回）
约 1 秒后收:  $PLATE,豫F·SQ818,93,42
```

- **必须设超时**：建议 **2 秒**。一帧约 1 秒，加上排队最坏约 1.5 秒。
- 超时没收到任何行 = **链路/摄像头异常**（不是"没识别到"），该重试或报警。
- 同一时刻只跑一帧：**收到回复（或超时）之后再发下一次触发**，不要连发。

### 2.3 解析结果 → 上报

```
$PLATE,<车牌>,<置信度0-100>,<帧号>[,img=<档位>]
```

| 字段 | 说明 |
| --- | --- |
| 车牌 | 合法车牌（7~8 位、省字开头）。**`-` 表示没认出来** |
| 置信度 | 0~100；车牌字段是 `-` 时这个值无意义，当 0 |
| 帧号 | 单调递增的内部计数，可用它去重 / 判断是不是新结果 |
| `img=` | 可选尾巴，给人看的提醒，**节点忽略即可**（按逗号切字段、只读前 3 个） |

## 3. 关键：怎么判断"认出来了"和"没认出来"

| 收到 | 含义 | 节点该怎么做 |
| --- | --- | --- |
| `$PLATE,豫F·SQ818,93,42` | 识别成功 | 正常上报 |
| `$PLATE,-,0,42` | **拍到了但没认出来**（太远/太糊/反光…） | 记一次"未识别"，**不要上报空车牌**；可提示用户靠近 |
| 什么都没有（超时） | **链路断了 / 摄像头没响应** | 重试 `AT+RUN`；连续失败则报警 |
| `OK` / `+INFO:...` 等其它行 | 你自己发命令的回复 | 按命令处理（触发帧只认 `$PLATE`） |

> 摄像头**保证**：只要它真的跑完了一帧，就一定有一行 `$PLATE`（认不出也是 `-`）。
> 所以「超时」和「`-`」是两件事，别混。

## 4. 推荐流程（伪代码）

```c
/* 检测到车辆停稳后调用 */
bool lpr_read(char *plate_out, int *conf_out)
{
    uart_send("AT+RUN\r\n");              /* 摄像头只认 \n, \r 会被忽略, 所以 \r\n 也安全 */

    char line[128];
    if (!uart_read_line(line, sizeof(line), 2000))   /* 2 秒超时 */
        return false;                     /* 链路异常: 调用方决定重试/报警 */

    if (strncmp(line, "$PLATE,", 7) != 0)
        return false;                     /* 不是结果行(理论上不会出现) */

    char *plate = line + 7;               /* 第 1 段: 车牌 */
    char *conf  = strchr(plate, ',');     /* 第 2 段: 置信度 */
    ...
    if (strcmp(plate, "-") == 0)
        return false;                     /* 拍到了但没认出来 */

    strcpy(plate_out, plate);
    *conf_out = atoi(conf);
    return true;
}
```

## 5. 可选：诊断与兜底命令

| 命令 | 回复 | 用途 |
| --- | --- | --- |
| `AT` | `OK` | 探活（1 秒内） |
| `AT+INFO` | 两行：`+INFO:...` + `+CFG:...` | 看版本 / 上行统计 / 当前设置；**只读，谁都能发** |
| `AT+PLATE` | `+PLATE:<车牌>,<置信度>,<帧号>,<是否合法>` | 查最近一次结果（丢了回复时补救） |
| `AT+PUSH` | `OK` + 一行 `$PLATE` | 把最近一次结果重推一遍 |
| `AT+CTRL=NODE` | `OK` | 如果调试时电脑把控制权抢走了，用这条拿回来 |

`AT+TEST=<车牌>`（注入假车牌）只在联调时用，正式流程不要发。

---

## 6. 注意事项

- 摄像头**不会主动发任何东西**（没有心跳、没有定时上报）—— 节点别等"推送"，要主动触发。
- **一次只发一行，不要连发**；控制口 RX FIFO 只有 128 字节。
- 行必须以**大写 `AT`** 开头；命令词大小写不敏感（`AT+run` 也行）。
- 一行的上限是 95 字节，超长整行被丢弃（且不回错）。
- 摄像头默认**只听触发**（`AT+TRIG=1`），不会自己连续拍；不要改成连续模式（那会让 `$PLATE` 变多、时序不可控）。
