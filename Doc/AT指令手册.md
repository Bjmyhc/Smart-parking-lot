# 车牌识别摄像头 · AT 指令手册

- **适用固件**：`PlateRecognitionIDF` **P5.78**（ESP32-S3 + GC2145，端侧 LPRNet 识别）
- **面向对象**：节点固件开发者（对接方）、现场调试人员
- **一句话**：摄像头平时一声不吭，只等你发 `AT+RUN` 拍一帧；认出来给结果，认不出来给原因。

---

## 1. 两条串口（先搞清楚"谁在说话"）

| 口 | 物理参数 | 时期 A（现在：只有电脑） | 时期 B（以后：接真节点） |
| --- | --- | --- | --- |
| **电脑口** | UART0 → CH340 → USB，**921600 8N1** | 唯一入口，既是"假节点"又是调试口 | 调试口（看日志、改设置） |
| **节点口** | UART1，TX=GPIO1 / RX=GPIO2，**115200 8N1** | **不存在**（`NODE_LINK_USE_UART1=0`） | 摄像头 → 节点 USART3 的那条线 |

- 时期 A 只有一条线：**电脑串口助手里发 AT、看结果**。
- 时期 B 两条线分工：**节点口只跑协议**（`$PLATE` 上行、AT 命令下行），**电脑口只看不发**（默认正常模式下）。
- 现在改 `NODE_LINK_USE_UART1=1` 重新编译，上半部分代码就切到时期 B，上层业务一行都不用改。

> ⚠️ **时期 A 下，电脑口默认不能发命令**（正常模式，主人是"节点"，可节点还没接）。
> 想发命令，先发一条 **`AT+CTRL=PC`** 把控制权抢过来。详见第 4 节。

## 2. 命令格式规则

| 规则 | 说明 |
| --- | --- |
| 前缀 | 必须以**大写字母 `AT`** 开头。写成小写 `at+run` 会被**静默丢弃**（不回错） |
| 命令词 | 大小写**不敏感**：`AT+IMG` = `at+IMG` = `At+Img`（前缀那两个字除外） |
| 分隔 | `AT+` 之后是命令名；`=` 之后是参数：`AT+IMG=3` |
| 三种用法 | 带 `=` → **设置**；不带 `=` → **查询当前值**；命令名后加 `?` → **看取值含义** |
| 行结束 | `\n` 结束一行；`\r` 被忽略（所以 `\r\n` 也行）；空行忽略 |
| 行长 | 一行最多 **95 字节**，超长**整行丢弃**（静默，防止半截命令被当真） |
| 发送节奏 | **一次只发一行，不要连发** —— 控制台 RX 只有 128 字节 FIFO，连发会被截断 |
| 响应时间 | 命令在主循环里被处理，一轮识别约 1 秒，所以最坏要等约 1 秒才回 |

### 2.1 回复规范（P5.74 起统一）

| 命令类型 | 回复 |
| --- | --- |
| 设置（带 `=`） | 成功 `OK`；失败 `ERR:<原因>` |
| 查询（不带 `=`） | 只回 `+XXX:<当前值>`，不带任何解释 |
| 看含义（`AT+XXX?`） | 多行取值说明 |
| 动作（`AT+RUN` 等） | 见各命令，**不一定回 `OK`** |

## 3. 命令总表

| 命令 | 查询回什么 | 设置回什么 | 作用 |
| --- | --- | --- | --- |
| `AT` | — | `OK` | 探活 |
| `AT+HELP` | — | 命令表 | 列出全部命令 |
| `AT+INFO` | 两行状态（见 5.4） | — | 版本 / 时长 / 统计 + 每条命令当前值 |
| `AT+CTRL` | `+CTRL:NODE\|PC` | `OK` | 控制权归谁 |
| `AT+PLATE` | `+PLATE:<车牌>,<置信度>,<帧号>,<是否合法>` | — | 查最近一次识别结果 |
| `AT+TEST=<车牌>` | — | `OK` + 一行 `$PLATE` | 注入测试车牌，验证上行链路 |
| `AT+PUSH` | — | `OK` + 一行 `$PLATE` | 把最近一次结果重推一遍 |
| `AT+RUN` | — | 不回 `OK`，直接出结果 | 立刻拍一帧（**节点触发就用这条**） |
| `AT+TRIG` | `+TRIG:0\|1` | `OK` | 触发方式：只听触发 / 连续自动 |
| `AT+LOG` | `+LOG:0\|1` | `OK` | 日志档位：简单 / 详细 |
| `AT+IMG` | `+IMG:0..3` | `OK` | 串口图片输出档位 |
| `AT+PAD` | `+PAD:0..3` | `OK` | 取样几何档（裁剪留白） |
| `AT+XXX?` | 多行说明 | — | 看该命令每个取值的含义 |
| `AT+HELP` / `AT+INFO` / `AT+XXX?` | — | — | **只读命令**：不看控制权，任何口任何模式都能发 |

## 4. 权限：控制权（`AT+CTRL`）

**规则**：一条命令两种模式，每个模式一个"主人"，另一个是"只能抢控制权"的旁观者。

| 模式 | 节点口（UART1） | 电脑口（USB 控制台） |
| --- | --- | --- |
| **正常模式**（`NODE`，**上电默认**） | 能发**全部**命令 | 只能发 `AT+CTRL` / `AT+IMG` / `AT+HELP` / `AT+INFO` / `AT+XXX?` |
| **调试模式**（`PC`） | 只能发 `AT+CTRL` / `AT+HELP` / `AT+INFO` / `AT+XXX?` | 能发**全部**命令 |

- 上电恒为正常模式，**不会自动切回**，重启即归还。
- 被拒绝时回：`ERR:没有权限: 现在是正常模式, 控制权在节点手里`（不解释你能发什么）。
- 切换控制权只回一行 `OK`，不打任何日志。
- **旁观者也能发的（P5.79）**：`AT+CTRL`（抢控制权）、`AT+HELP`（命令表）、`AT+INFO`（状态 + 每条命令当前值）、
  `AT+XXX?`（看取值含义）—— 这几条不看控制权，任何口、任何模式都能发。
- **`AT+IMG` 是特例**：只有**电脑口**能发（节点口发了没用），而且正常模式下也放行 —— 开图看画面不必先抢控制权。
- 除上面这些，其余命令（`AT` / `AT+PLATE` / `AT+TEST` / `AT+PUSH` / `AT+RUN` / `AT+TRIG` / `AT+LOG` / `AT+PAD`）
  **只有主人能发**。

## 5. 命令详解

### 5.1 `AT` —— 探活

```
AT          →  OK
```

### 5.2 `AT+HELP` —— 命令表

在串口上直接打印完整命令表（两边各有 `-----` 分隔线）。**只读命令，谁都能发（P5.79）**。

### 5.3 `AT+CTRL` —— 控制权

| 用法 | 回复 |
| --- | --- |
| `AT+CTRL` | `+CTRL:NODE` 或 `+CTRL:PC` |
| `AT+CTRL=PC` | `OK`（电脑成为主人，调试模式） |
| `AT+CTRL=NODE` | `OK`（节点成为主人，正常模式） |

**时期 A 调试第一步就是发 `AT+CTRL=PC`。**

### 5.4 `AT+INFO` —— 一眼看全（P5.78）

> 只读命令，**谁都能发**（P5.79）。

```
AT+INFO
+INFO:P5.78,运行123s,上线45行,收行120,坏命令0,被拒0,控制权=NODE,镜像=关,链路=console
+CFG:LOG=0,IMG=3,TRIG=1,PAD=1,PLATE=京Q06666,98,8
```

| 字段 | 含义 |
| --- | --- |
| `运行<秒>s` | 上电至今 |
| `上线<行>` | 已发出的 `$PLATE` 行数 |
| `收行<行>` | 收到的命令行数 |
| `坏命令<次>` | 语法错 / 未知命令次数 |
| `被拒<次>` | 因权限被拒的次数 |
| `控制权` | `NODE` / `PC` |
| `镜像` | 节点口对话是否抄送电脑口（时期 B 才可能"开"） |
| `链路` | `console`（时期 A）/ `uart1`（时期 B） |
| `+CFG` 行 | `LOG` / `IMG` / `TRIG` / `PAD` / `PLATE` 的当前值 |

### 5.5 `AT+PLATE` —— 查最近一次结果

```
AT+PLATE
+PLATE:京Q06666,98,8,1
```
字段：`<车牌>,<置信度0-100>,<帧号>,<是否合法>`。没认出来时车牌字段是 `-`、是否合法 `0`：

```
+PLATE:-,0,45,0
```

> 注意：`AT+TEST` 注入的车牌也会覆盖"最近一次结果"，所以 `AT+PLATE` 会返回注入值。

### 5.6 `AT+TEST=<车牌>` —— 注入测试车牌（不碰摄像头）

```
AT+TEST=豫F·SQ818
$PLATE,豫F·SQ818,100,5
OK
```
- 用来单独验证"上行链路 / 节点侧解析"，不需要真车牌、也不需要摄像头。
- 置信度恒为 100，帧号 = 上一次帧号 + 1。
- 没有可查询的值；不带参数发 `AT+TEST` 会回 `ERR:用法 AT+TEST=<车牌>`。

### 5.7 `AT+PUSH` —— 重推最近一次结果

```
AT+PUSH
$PLATE,京Q06666,98,8
OK
```

### 5.8 `AT+RUN` —— 立刻拍一帧 ★ 节点触发就用这条

```
AT+RUN
（受理时不回任何东西）
...约 1 秒后...
```
| 口 | 那一帧的回复 |
| --- | --- |
| 节点口（UART1） | `$PLATE,<车牌>,<置信度>,<帧号>[,img=<档位>]` |
| 电脑口（USB） | **结果块**（认出来）或 **未识别块**（没认出来，含原因） |

- **不回 `OK`**，别在它上面死等超时；节点侧有看门狗先喂狗。
- 不管认没认出来，**节点口一定有一行**（认不出就是 `$PLATE,-,0,<帧号>`）。
- 发图档位非 0 时，`$PLATE` 尾巴会多个 `,img=<档位>`，提醒你图忘了关。
- 摄像头当前不可用（开机自检没过、正在重试）时，电脑口给未识别块，原因写"摄像头当前不可用"。

### 5.9 `AT+TRIG` —— 触发方式

| 值 | 含义 |
| --- | --- |
| `AT+TRIG=1` | **只听 `AT+RUN`**（默认；开机不会自动拍） |
| `AT+TRIG=0` | 连续自动识别（每 200ms 一帧） |

```
AT+TRIG      → +TRIG:1
AT+TRIG=0    → OK
```
> 连续模式**失败帧不打未识别块**（会刷屏）；要看失败原因就单发 `AT+RUN`。

### 5.10 `AT+LOG` —— 日志档位

| 值 | 含义 |
| --- | --- |
| `AT+LOG=0` | **简单日志**（默认）：只打结果块 / 未识别块；ROI 行、候选表、掩码、警告全部不打 |
| `AT+LOG=1` | 详细日志：每帧补打完整诊断（定位 / 候选 / 掩码 / 缩略图 / 各种警告） |

也可以**长按 BOOT ≥2 秒**切换。

### 5.11 `AT+IMG` —— 串口图片输出档位

| 值 | 输出什么 |
| --- | --- |
| `AT+IMG=0` | **关**（默认；接真节点用这档） |
| `AT+IMG=1` | 干净预览图 320×240（画面 / 采数据） |
| `AT+IMG=2` | 预览图 + 绿框（看框套得准不准） |
| `AT+IMG=3` | 模型输入块 94×24（和推理输入逐像素一致） |

- **只有电脑口能改**这个档（节点口发了没用）；正常 / 调试模式都能改。
- 图片以 `$IMG,<字节数>` / `$END` 帧分隔输出，配 BY 串口助手可直接预览。
- 档位非 0 时，每条 `$PLATE` 尾巴都带 `img=<档位>` 提醒。
- 也可以**短按 BOOT** 循环切档。

### 5.12 `AT+PAD` —— 取样几何档（裁剪留白）

| 值 | 长边左端留白 | 右端留白 |
| --- | --- | --- |
| `0` | 净 0% | 净 4% |
| `1` | 净 +2% | 净 4% |
| `2` | 净 0% | 净 +7%（**默认**） |
| `3` | 净 −4%（往框里收） | 净 +7% |

也可以**连按 BOOT 三下**循环切档。

### 5.13 `AT+XXX?` —— 看某条命令的取值含义

```
AT+IMG?
+IMG?:串口图片输出档位
   0 = 关 (不发图; 默认档, 接真节点用这档)
   1 = 干净预览 320x240
   2 = 预览 + 绿框
   3 = 模型输入块 94x24
   权限: 只有电脑口能改这个档(节点口发了没用); 正常/调试模式都一样能改
   设置 AT+IMG=0..3 回 OK;  查询 AT+IMG 回 +IMG:<档位>
```
支持：`CTRL / INFO / PLATE / TEST / PUSH / RUN / TRIG / LOG / IMG / PAD / HELP`。
**不碰权限闸门**，任何口、任何模式都能看。

## 6. 上行数据（摄像头 → 节点）

### 6.1 `$PLATE` 行（机器读的）

```
$PLATE,<车牌>,<置信度0-100>,<帧号>[,img=<档位>]
```
- 每处理完一帧发一行；**没认出来时车牌字段是 `-`**（节点只认这个字段判断"有没有车牌"）。
- 语法不合法的结果（例如 `京8`）**不会**上报，一律发 `-`，避免节点把半截结果当车牌。
- 节点按逗号切字段、**只读前 3 个**即可，`img=` 是可选的提醒字段。

### 6.2 结果块（人读的，打给电脑口）

```
========================================
车牌号码: 京Q06666
车牌颜色: blue
置信度:   98.00%
帧号:     8
车牌位置: (290,232) -> (597,413)
========================================
```

### 6.3 未识别块（人读的，只给被 `AT+RUN` 点名的那一帧）

```
========================================
车牌号码: - (未识别)
原因:     画面里没有一块车牌色 —— 车牌太小/太远/太暗, 或者偏色
帧号:     175
========================================
```
常见原因：没有车牌色 / 有颜色没矩形（含最接近候选的数值）/ 每块都太大（反光连片）/ 框太小（离太远）/
模型 18 步全空白 / 字符不合法 / 取帧失败 / 摄像头不可用。

## 7. 典型流程

### 7.1 现在（时期 A，只有电脑）

```
电脑口(COM10 @921600)                      摄像头
  |-- AT+CTRL=PC ------------------------>  |  控制权抢过来(调试模式)
  |<-- OK --------------------------------  |
  |-- AT+TRIG=1 ------------------------->  |  确认"只听触发"(默认就是)
  |<-- OK --------------------------------  |
  |-- AT+RUN ---------------------------->  |  去拍一帧
  |<-- ======= 结果块 / 未识别块 ========  |  约 1 秒后(电脑口看这个)
  |-- AT+INFO --------------------------->  |  想核对设置/统计
  |<-- +INFO:... / +CFG:... ------------   |
```

### 7.2 以后（时期 B，接了真节点）

```
节点(检测到车)                              摄像头
  |-- AT+RUN --------------------------->  |  不回 OK, 直接去拍
  |                                         |  拍一帧 -> 定位 -> 推理 (约 1s)
  |<-- $PLATE,豫F·SQ818,93,42 ----------   |  回复 = 这一帧的识别结果
  |                                         |  (没认出就是 $PLATE,-,0,<帧号>)
```
节点侧要点：**发一次触发，必定收到一行**（认不出也是 `-`），所以别用"有没有回复"判断是否识别成功，
要判断**车牌字段是不是 `-`**。

## 8. BOOT 按键手势（不开电脑也能改设置）

| 手势 | 动作 |
| --- | --- |
| 短按（<1s，且 400ms 内没有第二下） | 循环切 `AT+IMG` 档位（0→1→2→3→0） |
| 双击（400ms 内两下） | 图片输出复位 + 打一张发图统计（串口图卡住时救急） |
| 三击 | 循环切 `AT+PAD` 档位 |
| 1~2s | 空档，当作没按（手抖按久了不误触） |
| 长按（≥2s） | 切换 `AT+LOG` 日志档位 + 图片输出复位 |

## 9. 错误信息速查

| 串口上看到 | 意思 | 怎么办 |
| --- | --- | --- |
| `ERR:没有权限: 现在是正常模式, 控制权在节点手里` | 你是旁观者 | 先发 `AT+CTRL=PC` |
| `ERR:未知命令 XXX (发 AT+HELP 看命令表)` | 命令名拼错 / 不存在 | 发 `AT+HELP` |
| `ERR:命令要以 AT+ 开头 (发 AT+HELP 看命令表)` | 例如发了 `ATFOO` | 补上 `+` |
| `ERR:用法 AT+CTRL=NODE\|PC (发 AT+CTRL? 看取值含义)` | 参数写错 | 发 `AT+CTRL?` |
| `ERR:用法 AT+TEST=<车牌>` | 少了参数 | 补车牌 |
| `ERR:用法 AT+LOG=0\|1 ...` / `AT+IMG=0..3 ...` / `AT+TRIG=0\|1 ...` / `AT+PAD=0..3 ...` | 参数超出范围 | 发对应的 `AT+XXX?` |
| `ERR:现在拍不了 (主固件没受理 AT+RUN)` | 内部异常 | 重启设备 |
| 什么都不回 | 行开头不是大写 `AT` 或行太长 | 检查格式 / 行长（≤95 字节） |
