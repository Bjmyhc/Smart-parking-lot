## 主文档怎么读（它太长了）

按"先结论后过程"的顺序：

1. **一、结论速览** + **二、进度总览** —— 一屏看完现在到哪了（P4 崩溃的三个根因）
2. **第四十九节 / 第五十节** —— 最新状态与最后一次量化对照实验（截至 2026-10-08）
3. 想知道某个具体现象（框偏胖、省字塌缩、反光、切边、多认一个字…），按目录搜小节标题，
   每节基本是"现场日志 → 根因 → 改动 → 验证"四段式
4. **第四十二节**是分水岭：之前主要在调几何/裁剪，之后发现"int8 的损失主要来自校准算法"

## 维护约定

- 结论写进主文档时**要连着数据一起写**（哪台设备、哪次日志、多少张样本），否则下次没法复现；
- 被推翻的结论**别删**，就地更正（第四十二节 vs 第五十节就是例子），保留"当时为什么那么想"；
- 一次性实验脚本按 `tools/` 的命名约定放，产物进 `tools/out/`（已忽略）。
